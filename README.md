# Кино ТВ

Личное приложение для Android TV и Android-телефона: открывает выбранный сайт на весь экран, без адресной строки, с блокировкой рекламы, всплывающих окон и редиректов.

## Установка
Скачать **KinoTV.apk** из [Releases](../../releases/latest) и установить (на ТВ — через Downloader или флешку).

## Управление пультом
| Кнопка | Действие |
|---|---|
| Стрелки | двигать курсор; у края экрана — прокрутка страницы |
| ОК | нажать |
| Долгое ОК / «Меню» | меню приложения (главная, обновить, адрес сайта, вид сайта, курсор, обновления) |
| Назад | назад по страницам; из видео — выход из полноэкранного режима |
| В полноэкранном видео | ←/→ — перемотка плеером, ОК — пауза, ↑/↓ — показать курсор |

## Обновления
- **Тихие**: правка `remote/config.json` (рекламные домены, правила скрытия) — приложение подхватит само при следующем запуске.
- **Новая версия**: любое изменение в `app/` → GitHub сам собирает APK и публикует релиз → приложение при запуске предлагает «Установить». Вход и настройки сохраняются.

## Если сайт не открывается
Приложение показывает причину: нет интернета, DNS-блокировка, сброс соединения, 403/451 (ограничение по IP или стране), ошибка сервера.
